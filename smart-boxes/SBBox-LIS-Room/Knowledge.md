# Knowledge — SBBox-LIS-Room

## 1. Educational Context

SBBox-LIS-Room is a learning communication space designed
for an AI-Native University environment.

A Learning Room provides a temporary, context-bound space
where teachers and learners can connect around a learning event.

The purpose of the room is not merely to transmit messages.

It is the first layer of a future Knowledge Flow.

---

## 2. Core Concepts

### 2.1 Learning Room

A Learning Room is a bounded digital context associated
with a specific learning activity, class, event, or topic.

A room contains:

- Room identity
- Teacher identity
- Learner access
- Learning messages
- Learning context

---

### 2.2 Teacher Broadcast

Teacher Broadcast is an official information flow
from the teacher to learners.

In version 0.1, only the teacher is allowed
to publish official messages.

---

### 2.3 Student Access

Students access the Learning Room through
a shared access link or QR code.

The first version prioritizes simplicity:

Teacher → Broadcast → Students

---

### 2.4 Message Stream

A Message Stream is an ordered sequence of
learning-related messages inside a Learning Room.

Each message should preserve its context and provenance.

Important information may include:

- Author
- Time
- Room
- Content
- Message type

---

### 2.5 Knowledge Candidate

Not every message is knowledge.

A message may become a Knowledge Candidate
when it contains information, explanation,
question, insight, example, decision, or other
material that may have future learning value.

Therefore:

Message ≠ Knowledge

Message → Knowledge Candidate → Validated Knowledge

---

## 3. Knowledge Lifecycle

The Learning Room is designed as the first stage
of a future knowledge lifecycle.

```text
Learning Event
      ↓
Learning Room
      ↓
Message Stream
      ↓
Knowledge Candidate
      ↓
Validation
      ↓
Knowledge Atom
      ↓
Knowledge Graph
      ↓
Living Book
      ↓
New Learning Experience
