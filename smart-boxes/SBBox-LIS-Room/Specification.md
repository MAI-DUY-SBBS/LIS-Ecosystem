# SBBox-LIS-Room

## Identity

Name:
SBBox-LIS-Room

Version:

Domain:
AI-Native University

Type:
Learning Communication Smart Box


## Purpose

SBBox-LIS-Room provides a lightweight learning communication space
where teachers and students can connect, share information,
and preserve learning interactions.


## Capability

The Smart Box provides:

- Create learning room
- Generate access link
- Generate QR code
- Broadcast teacher messages
- Allow students to access learning information


## Input

- Room name
- Teacher identity
- Student access request


## Output

- Learning room URL
- QR code
- Message stream


## Future Evolution

SBBox-LIS-Room can evolve toward:

- AI learning assistant
- Knowledge extraction
- Living Book integration
- Learning Intelligence Infrastructure
