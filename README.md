# LIS-Ecosystem

## Learning Intelligence Infrastructure

An AI-Native University Knowledge Ecosystem.

---

## Vision

LIS aims to build a new generation of learning infrastructure
where humans and AI collaborate to create, share, and evolve knowledge.

---

## SBBS Philosophy

This project follows the Smart Black Box System (SBBS) philosophy:

- Capability first
- Specification before implementation
- Reusable intelligence
- Composable Smart Boxes

A Smart Box is not only software code.
It contains:

- Identity
- Specification
- Interface
- Implementation
- Knowledge
- Rules

---

## First Smart Box

### SBBox-LIS-Room

A lightweight AI-Native classroom communication system.

Purpose:

- Create learning rooms
- Connect teachers and students
- Preserve learning conversations
- Prepare future Knowledge Extraction
